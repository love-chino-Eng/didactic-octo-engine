## 5.1 测试方法与实测数据

将比特流与应用程序下载至开发板后，在 PC 端以 115200-8-N-1 打开串口终端，按提示完成 3 轮测试。实测的一局完整记录如下：

```
  >>> LED1 ON  -- press BTN1 now!
  hit BTN1  (target BTN1)
  reaction: 1761.719 ms
  [SLOW] +5

--- Round 2 / 3 ---
  wait 4501 ms ...
  >>> LED0 ON  -- press BTN0 now!
  hit BTN0  (target BTN0)
  reaction: 1766.936 ms
  [SLOW] +5

--- Round 3 / 3 ---
  wait 2577 ms ...
  >>> LED1 ON  -- press BTN1 now!
  hit BTN1  (target BTN1)

  rounds 3 / hits 3 / wrong 0 / timeout 0 / false start 0
  total score 15 / average 1971.628 ms
```

## 5.2 结果分析

1. **计时链路正确**。三轮的反应时间分别为 1761.719 ms、1766.936 ms、2386.230 ms，与人工计时的量级一致，且小数位稳定输出，说明 32 位计时值经 `us = cycles/100` 换算后打印正确（1 ms 对应 100 000 个 100 MHz 计数）。

2. **灯序与按键判定正确**。三轮目标灯分别为 LD1、LD0、LD1，玩家按下 BTN1、BTN0、BTN1 均被判定为正确，`wrong button` 计数保持 0，说明 CH2 的 `btn_index` 字段与 LED 的 one-hot 控制字对应关系一致，one-hot 编码与位偏移（stim_led 位于 [4:1]）无误。

3. **随机延时生效**。三次等待时间分别为 2422 ms、4501 ms、2577 ms，落在设定的 1000～5000 ms 区间内，且灯序不重复，说明 xorshift 伪随机序列与种子构造有效。

4. **成绩偏慢的原因**。本次平均反应时间 1971.628 ms，明显高于常人的简单视觉反应时间（约 200～250 ms）。主要原因有三：其一，本实验的刺激是“某颗 LED 亮起后还要辨认编号并找到对应按键”，属于“辨别—选择—反应”任务，认知环节显著多于简单反应；其二，板载按键行程短、手感偏硬，且实验者首次操作对位置不熟悉；其三，实验环境光照较强，LED 亮度对比度有限。随着练习次数增加，该值会明显下降，这也说明本装置可以作为反应力训练或注意力测试的量化工具。

5. **测量精度与误差来源**。硬件量化误差为 ±1 个时钟周期（±10 ns），相对 1 s 量级的测量值可以忽略；串口打印耗时、PS 轮询周期均发生在锁存之后，不影响测量结果。实际误差主要来自人因（视觉辨识与手指动作）以及按键机械延迟，属于被测对象本身的特性而非仪器误差。

## 5.3 改进方向

- 增加“预备—刺激”节律提示（如提示音），减少等待期的注意力波动；
- 将 LED 与按键的对应关系随机重映射，避免记忆效应，提高测试有效性；
- 把随机延时与点灯逻辑移入 PL（LFSR 实现），使 PS 完全不参与时序，进一步降低软件抖动的影响；
- 将按键实时电平接入 GPIO 的空闲位，解决“按住不放跨轮”无法判定的问题，并支持长按/连击统计；
- 增加多局平均、标准差与最快/最慢成绩统计，形成完整的反应力评估报告。
